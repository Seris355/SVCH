# Лабораторная работа №6 - Мастер-классы по здоровому питанию

Express-сервер для управления мастер-классами по здоровому питанию.

## Структура проекта

```
express-app/
├── server.js                  # Express-сервер
├── public/
│   ├── index.html            # HTML-файл с фронтенд-кодом
│   └── style.css             # CSS-стили
├── data/
│   └── masterclasses.json    # JSON-файл с данными
├── package.json              # Зависимости
└── README.md                 # Документация
```

## Установка и запуск

```bash
cd express-app
npm install
npm start
```

Сервер запустится на `http://localhost:4000`

### Остановка сервера

**Windows (PowerShell/CMD):**
- Нажмите `Ctrl + C` в терминале, где запущен сервер
- Или закройте окно терминала

**Альтернативный способ (если сервер не останавливается):**
```bash
# Найти процесс на порту 4000
netstat -ano | findstr :4000

# Остановить процесс (замените PID на номер из предыдущей команды)
taskkill /PID <номер_процесса> /F
```

**Linux/Mac:**
- Нажмите `Ctrl + C` в терминале
- Или используйте: `killall node`

## Реализованные сервисы

### 1. GET-сервис, возвращающий веб-страницу с фронтенд-кодом

**Маршрут:** `GET /`

**Описание:** Возвращает HTML-файл (`index.html`) с встроенным JavaScript-кодом для работы с API.

**Пример:**
```
http://localhost:4000/
```

---

### 2. GET-сервис, возвращающий данные в формате JSON

**Маршрут:** `GET /api/masterclasses`

**Описание:** Возвращает список всех мастер-классов из JSON-файла.

**Ответ:**
```json
[
  {
    "id": 1,
    "name": "Холестерин и энергия",
    "description": "Как снизить холестерин диетой...",
    "participants": 9,
    "doctors": 1,
    "date": "2025-02-24"
  }
]
```

**Где вызывается:** При загрузке страницы и при нажатии кнопки "Обновить список".

---

### 3. POST-сервис, возвращающий данные в формате JSON

**Маршрут:** `POST /api/masterclasses`

**Описание:** Создаёт новый мастер-класс и возвращает созданный объект.

**Тело запроса:**
```json
{
  "name": "Название",
  "description": "Описание",
  "participants": 0,
  "doctors": 0,
  "date": "2025-03-15"
}
```

**Ответ:** `201 Created`
```json
{
  "id": 1234567890,
  "name": "Название",
  "description": "Описание",
  "participants": 0,
  "doctors": 0,
  "date": "2025-03-15"
}
```

**Где вызывается:** При нажатии кнопки "Добавить мастер-класс".

---

### 4. POST-сервис, принимающий данные

**Маршрут:** `POST /api/masterclasses/:id/feedback`

**Описание:** Принимает произвольные данные (отзыв, обратную связь) и возвращает подтверждение.

**Тело запроса:**
```json
{
  "comment": "Отличный мастер-класс!",
  "rating": 5
}
```

**Ответ:**
```json
{
  "status": "received",
  "id": "1",
  "received": { "comment": "Отличный мастер-класс!", "rating": 5 },
  "message": "Спасибо за обратную связь!"
}
```

**Где вызывается:** Можно использовать для отправки отзывов (в текущей реализации доступно через API).

---

### 5. DELETE-сервис для удаления данных

**Маршрут:** `DELETE /api/masterclasses/:id`

**Описание:** Удаляет мастер-класс по ID.

**Ответ:** `204 No Content`

**Где вызывается:** При нажатии кнопки "Удалить" на карточке мастер-класса или "Удалить выбранные".

---

### 6. Сервис для получения данных в формате XML/HTML/JSON в зависимости от заголовка Accept

**Маршрут:** `GET /api/masterclasses/export`

**Описание:** Возвращает данные в формате, указанном в заголовке `Accept`.

**Форматы:**
- `Accept: application/json` → возвращает JSON-файл для скачивания
- `Accept: application/xml` → возвращает XML-файл
- `Accept: text/html` → возвращает HTML-таблицу

**Пример XML:**
```xml
<?xml version='1.0'?>
<masterclasses>
  <masterclass>
    <id>1</id>
    <name>Холестерин и энергия</name>
    ...
  </masterclass>
</masterclasses>
```

**Где вызывается:** При нажатии кнопок "Скачать JSON/XML/HTML".

---

### 7. GET-сервис, возвращающий HTML-страницу (дополнительный)

**Маршрут:** `GET /page`

**Описание:** Возвращает простую HTML-разметку со списком мастер-классов (без полной HTML-структуры документа).

**Ответ:**
```html
<h1 style="color: #892c45;">Мастер-классы по здоровому питанию</h1>
<p style="font-size: 18px;">Список доступных мастер-классов:</p>
<div style="border: 1px solid #ccc; padding: 10px; margin: 10px 0;">
  <h3>Холестерин и энергия</h3>
  ...
</div>
```

**Где вызывается:** При нажатии кнопки "Загрузить HTML-страницу" — HTML вставляется на текущую страницу.
